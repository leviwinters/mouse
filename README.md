## Project overview

<div align="center">
</div>
<br />
<b>Mouse</b> is a full-stack Next.js storefront for a premium lightweight gaming mouse, featuring a clean interface inspired by Stripe's design patterns.

### Technical highlights

- Built with React and Next.js for fast, server-rendered pages and SEO.
- Styled Components for component-scoped CSS-in-JS.
- Stripe Checkout for secure, PCI-compliant payments.
- PostgreSQL via pg for efficient database queries.
- AWS Cognito for user authentication and management.
- AWS S3 and CloudFront for static asset storage and global CDN delivery.

### Functional capabilities

- Browse and purchase products with an intuitive interface.
- Responsive design for consistent use across devices.
- Secure checkout powered by Stripe.
- User accounts with authentication and order history.
- Persistent shopping cart using localStorage, syncing when users sign up.
- Guest checkout allows purchases without creating an account.
